# Cold-tide
In this game you are a detective that came in a town to find a murder on a beach but then you find another murder . You have 21 days to find both murders.

# Hints
There are hints in the game if you press H on a keyboard and a hint will appear.
You have a notebook on N so you can track the points on every murder.

# Languages
To change the language go to settings and you can choose the language from English,French,German and Chinese.
